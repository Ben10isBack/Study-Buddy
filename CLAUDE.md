# StudyDesk Developer Guide

StudyDesk is an academic execution and planning application built with React 19, Vite, Capacitor 8 (Android), and Electron (Desktop).

**Author & Developer:** shourya Vaidhya jain (<parvx18@gmail.com>)

## Quick Commands
- Install dependencies: `npm install`
- Dev server: `npm run dev`
- Run test suite: `npm test`
- Production build: `npm run build`
- Android sync: `npx cap sync android`
- Open in Android Studio: `npx cap open android`
- Desktop dev: `npm run electron:dev`
- Desktop build: `npm run electron:build`
